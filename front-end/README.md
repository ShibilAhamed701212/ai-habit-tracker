# AI Habit Tracker — frontend

React 19 + Vite 8 single-page app. Setup, environment variables, screenshots and the API it talks to are documented in the [root README](../README.md).

```bash
cp .env.example .env   # VITE_API_URL=http://localhost:8000/api
npm install
npm run dev            # http://localhost:5173
npm run lint
npm run build
```
